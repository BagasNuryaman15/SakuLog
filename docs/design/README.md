# SakuLog Design Documentation

This folder contains the active design direction for SakuLog and archived historical design documents.

## Active Source of Truth

- Design source of truth: `docs/design/dashboard-v1-5-design-direction.md`
- Product source of truth: `docs/product/PRD_V1_5.md`
- Visual reference: `docs/product/references/sakulog-dashboard-v1-5-concept.png` when the asset is available.

## Archive

Legacy dashboard layer documents live in `docs/design/archive/legacy-dashboard-layers/`.
The archived V1 PRD lives in `docs/product/archive/PRD_V1_ARCHIVED.md`.

Those files are historical only. Do not use the Layer 1, Layer 2, Layer 3A, or old dashboard UI spec documents as the active implementation reference for SakuLog V1.5.

For new dashboard work, follow the V1.5 PRD and the active dashboard design direction. If the concept image is not available in the project, do not create a replacement image.

Files outside the active source of truth are references or historical materials unless the V1.5 PRD or design direction explicitly says otherwise.
